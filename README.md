## /flagship — Gesture OS

<div align="center">

### 🖐️ GestureOS
**Touchless · Spatial · Extensible**

</div>

GestureOS turns an ordinary webcam into a touchless desktop interaction layer. The project combines hand/face/body perception, gesture recognition, safety controls, native input dispatch, and a 3D spatial UI.

**Current highlights**

`25+ gestures` · `3D Spatial UI` · `AirMouse` · `on-device vision` · `plugin architecture` · `gesture studio`

Built around **Python, MediaPipe, Qt/PySide, computer vision, temporal filtering, and event-driven architecture**.

[**Explore GestureOS →**](https://github.com/akaKRISH/GestureOS)
